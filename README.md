# 应急广播脚本演练发布台

这是面向公共场馆应急信息团队的浏览器工作台，用于编制分段广播脚本、冻结适用基线、执行确定性校验、登记计时演练、跟踪整改并由独立人员批准后生成可核验发布包。数据保存在本地目录，方案版本、校验批次和发布内容使用 SHA-256 摘要寻址。

工作台包含方案状态检索与稳定分页、草拟脚本续编、基线预检、校验批次差异、演练完整性和时长偏差分析、整改任务批量推进、批准审阅快照，以及发布清单下载和浏览器离线逐项核验。所有写操作均受修订号和请求幂等标识保护，已发布和已拒绝方案保持只读。

标准构建：

```text
go build ./cmd/broadcastdesk
```

运行服务（默认监听 `127.0.0.1:19081`）：

```text
go run ./cmd/broadcastdesk -addr=127.0.0.1:19081 -data=./data
```

也可以设置 `PORT=19082`，服务会绑定 `127.0.0.1:19082`。浏览器打开服务地址即可使用工作台。

测试与自检：

```text
go test ./...
go run ./cmd/broadcastdesk -selfcheck -addr=127.0.0.1:19081
```
